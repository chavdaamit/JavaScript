# 📦 JavaScript Array Methods Project

This project demonstrates various **JavaScript Array methods** using an interactive UI.  
Users can dynamically create an array and perform operations like push, pop, shift, sort, filter, map, reduce, etc.

## ▶️ How It Works

### Step 1: Enter Number
Enter how many elements you want in array.

### Step 2: Create Array
Click **Create Array** to generate array.

### Step 3: Perform Operations
Use buttons like:
- Push
- Pop
- Shift
- Sort
- Filter
- Map
- Reduce etc.

### Step 4: Output
Result will be displayed in **Output Section**

## 📘 Array Methods Used

| Method | Description |
|------|-------------|
| push() | Add element at end |
| pop() | Remove last element |
| shift() | Remove first element |
| unshift() | Add element at beginning |
| reverse() | Reverse array |
| toString() | Convert array to string |
| length | Get array length |
| indexOf() | Find index |
| includes() | Check value exists |
| sort() | Sort array |
| find() | Find first match |
| some() | Check condition true |
| every() | Check all condition |
| filter() | Filter array |
| map() | Transform array |
| reduce() | Sum of array |
| slice() | Get portion of array |
| join() | Join array into string |
